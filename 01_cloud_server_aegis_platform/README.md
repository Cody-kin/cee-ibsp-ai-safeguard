# AI-SafeGuard Cloud Server / Web Platform

This folder contains the cloud platform source code for AI-SafeGuard.

Main functions:
- FastAPI backend
- Web dashboard
- Events and alerts page
- Devices and LoRa page
- Sensor analytics
- LoRaWAN HTTP integration
- Remote control and OTA command support
- Event database integration

Sensitive files such as .env, passwords, database dumps and upload folders are excluded from this submission.
