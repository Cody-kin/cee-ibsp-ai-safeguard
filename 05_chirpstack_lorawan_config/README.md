# ChirpStack / LoRaWAN Configuration

This folder contains the ChirpStack Docker configuration used by AI-SafeGuard.

Main purpose:
- Manage 255MESH LoRaWAN Gateway
- Manage Heltec Wireless Stick V3 Node1
- Use AS923 region
- Forward LoRaWAN uplink payloads to the cloud server
- Support downlink command path for remote control

Database volumes and runtime data are excluded.
